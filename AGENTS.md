# AGENTS.md — Project State Governance

Before making broad or structural changes in this repository:

1. Read `PROJECT_STATE_GOVERNANCE.md`.
2. Read the project's Canonical Current State in Notion.
3. Inspect `main` and any registered parallel branches before recreating assets, brand, architecture, or UX.
4. Respect any item marked CANONICAL / DO NOT REDESIGN / DO NOT REBUILD / PRESERVE.
5. Do not assume `main` contains every approved decision.
6. If a parallel branch contains an approved implementation, prefer selective transplant/cherry-pick over recreating it.
7. At the end of a relevant round, report:
   - branch
   - commit
   - files changed
   - tests/build
   - deploy status
   - approved state
   - pending items
   - exact next step
8. The closeout is incomplete until the canonical project state in Notion has been updated, either directly or via a handoff block ready for update.

For trivial edits, keep the process lightweight.
